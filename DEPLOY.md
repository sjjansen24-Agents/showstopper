# Deploying floor-view-live (static)
This folder is the whole site. It's plain static files with no build step:
- index.html, styles.css, theme.css, app.js, social.js, social-supabase.js, ads.js, fade.js, data.js, stage.webp
- config.js (public Supabase URL + **anon key only**; RLS protects the data)
- advertise/index.html (a redirect so /advertise works on any static host)

Never put the service-role key, the YouTube key, or the DB URL in this folder.
data.js is regenerated by `python3 backend/ingest/daily.py`. Redeploy after each run, or let a CI job run daily.py and redeploy.

Any static host works:
- Cloudflare Pages: `npx wrangler pages deploy . --project-name showstopper`
- Netlify: `npx netlify deploy --dir . --prod`
- Vercel: `npx vercel deploy --prod`
- GitHub Pages: push this folder to a repo and enable Pages.

After deploying, add the production origin to Supabase:
- Auth → URL Configuration: Site URL and Redirect URLs.
- Your CORS allow-list, if you set one.
